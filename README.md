# Bayou Blues Reimagined

It adds a brand-new swamp biome to the game — the Bayou.

The Bayou is rich in vegetation, including cypress trees, Spanish moss, algae, gooseberries, and plantable lilies.

The mod also adds a series of foods made from gooseberries, as well as vanilla-style swamp foods.

This mod is an unofficial remake of Bayou Blues, Bayou Delight and Better Badlands.
